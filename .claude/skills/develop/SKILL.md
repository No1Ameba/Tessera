# Develop Skill Workflow

AI 에이전트는 코드 작성 시 이 워크플로우의 단계를 엄격하게 순서대로 따라야 한다. 현재 단계가 완벽하게 컴파일되고 동작하기 전에는 다음 단계로 넘어가지 않는다.

## Phase 1: 아키텍처 뼈대 및 IPC 구축
1. CMake 기반 크로스 플랫폼 빌드 시스템 세팅.
2. OS별 IPC 계층 추상화 및 구현 (Unix Socket / Named Pipe).
3. 데몬 프로세스 스폰 및 클라이언트와의 통신 연결 테스트.
4. 데몬 내 OS별 PTY 스폰 로직 (ConPTY / `pty.h`) 기초 구현.

## Phase 2: 터미널 백엔드 및 렌더링 루프 연결
1. 기본 ANSI 이스케이프 시퀀스 파서 구현.
2. 클라이언트 쪽에 GPU 가속 윈도우 생성 및 텍스트 렌더링 뼈대 작성.
3. 데몬에서 PTY 출력을 캡처하여 클라이언트로 스트리밍.
4. 클라이언트 화면에 표준 텍스트 입출력이 정상적으로 렌더링 되는지 확인.

## Phase 3: 타일링 로직 및 UI 관리
1. 화면 분할(Split)을 관리할 트리(Tree) 데이터 구조 설계 및 구현.
2. 클라이언트 UI에 다중 터미널 패널 렌더링 로직 적용.
3. 설정 파일(JSON/TOML) 파서 연동 및 테마, 폰트 적용.

## Phase 4: 미디어 및 PDF 통합 (Advanced)
1. 터미널 렌더링 엔진 내에 지정된 이미지 프로토콜(Kitty/Sixel) 디코딩 및 화면 출력 로직 구현.
2. 외부 라이브러리(MuPDF 등) 빌드 연동.
3. 데몬 또는 전용 워커에서 PDF를 비트맵으로 변환 후 클라이언트에 전송하여 터미널 내 출력.
